# API reference

Generated by `scripts/gen_api_docs.py` from the code; do not edit by hand.
`load`, `Export`, `Generation`, `Span`, `Usage` and `SuppliedCost` are also exported
from the top-level `tracecost` package.

## Loading

### `tracecost.readers.load(*paths: str | pathlib.Path) -> tracecost.model.Export`

Read one or more export files of any supported format into one Export.

### `tracecost.model.Export`

Dataclass with fields: `spans, generations, sources, trace_meta`.

Everything read from one or more files.

### `tracecost.model.Generation`

Dataclass with fields: `trace_id, span_id, parent_id, name, model, provider, usage, supplied_cost, session_id, user_id, service_tier, kind, source`.

One LLM (or embedding) call with everything pricing and rollups need.

### `tracecost.model.Span`

Dataclass with fields: `trace_id, span_id, parent_id, name, kind, start_ns, end_ns, session_id, user_id`.

Any span in the export, generation or not. Needed to roll cost up to roots.

### `tracecost.model.Usage`

Dataclass with fields: `input_tokens, output_tokens, cache_read_tokens, cache_write_tokens, reasoning_tokens, cache_reported`.

Token counts for one LLM call, in OpenTelemetry GenAI semantics.

`input_tokens` is the total prompt size *including* cache reads and writes, and
`output_tokens` is the total completion size *including* reasoning tokens. That is how the
OTel registry defines them ("The value SHOULD be included in gen_ai.usage.input_tokens").
Readers for dialects that store exclusive counts (Langfuse) convert on the way in.

`cache_reported` records whether the exporter wrote *any* cache attribute. Zero cache tokens
with `cache_reported=False` may mean "no cache" or "not reported" (ollama#15758), and the
report says so.

### `tracecost.model.SuppliedCost`

Dataclass with fields: `amount, currency, source`.

A cost the instrumentation already computed and attached to the span.

## Pricing

### `tracecost.prices.PriceTable`

Dataclass with fields: `providers, snapshot_date, source`.

### `tracecost.prices.PriceTable.load(path: str | pathlib.Path | None = None) -> tracecost.prices.PriceTable`

Load the bundled snapshot, or a table file of the same shape.

### `tracecost.prices.PriceTable.with_overrides(self, path: str | pathlib.Path) -> tracecost.prices.PriceTable`

Return a table where models in *path* win over the snapshot's.

### `tracecost.prices.PriceTable.find(self, model: str, provider: str | None = None) -> tracecost.prices.Match | None`

### `tracecost.prices.price_export(export: tracecost.model.Export, table: tracecost.prices.PriceTable, *, recompute: bool = False, at: datetime.datetime | None = None) -> list[tracecost.prices.PricedGeneration]`

Price every generation, using each span's start time for dated prices when known.

### `tracecost.prices.price_generation(generation: tracecost.model.Generation, table: tracecost.prices.PriceTable, *, at: datetime.datetime | None = None, recompute: bool = False) -> tracecost.prices.Cost`

Supplied cost wins unless *recompute*; the table is the fallback and the audit.

### `tracecost.prices.price_from_table(generation: tracecost.model.Generation, table: tracecost.prices.PriceTable, at: datetime.datetime | None = None) -> tracecost.prices.Cost`

Price *generation* from the table regardless of any supplied cost.

### `tracecost.prices.resolve_rates(model: dict[str, typing.Any], at: datetime.datetime, service_tier: str | None) -> tuple[dict[str, typing.Any], list[str]]`

### `tracecost.prices.Cost`

Dataclass with fields: `amount, currency, source, model_id, provider_id, breakdown, notes`.

The priced result for one generation.

### `tracecost.prices.PricedGeneration`

Dataclass with fields: `generation, cost, recomputed`.

## Attribute dialects

Which span attributes each reader looks at, in order of preference (`tracecost.readers.dialects`).

| field | OTel GenAI (`gen_ai.*`) | OpenInference (`llm.*`) |
|---|---|---|
| model | `gen_ai.response.model`, `gen_ai.request.model` | `llm.response.model_name`, `llm.model_name`, `llm.request.model_name` |
| provider | `gen_ai.provider.name`, `gen_ai.system` | `llm.provider`, `llm.system` |
| input tokens (total) | `gen_ai.usage.input_tokens`, `gen_ai.usage.prompt_tokens` | `llm.token_count.prompt` |
| output tokens (total) | `gen_ai.usage.output_tokens`, `gen_ai.usage.completion_tokens` | `llm.token_count.completion` |
| cache read | `gen_ai.usage.cache_read.input_tokens`, `gen_ai.usage.cache_read_input_tokens` | `llm.token_count.prompt_details.cache_read` |
| cache write | `gen_ai.usage.cache_write.input_tokens`, `gen_ai.usage.cache_creation.input_tokens`, `gen_ai.usage.cache_creation_input_tokens` | `llm.token_count.prompt_details.cache_write` |
| reasoning | `gen_ai.usage.reasoning.output_tokens` | `llm.token_count.completion_details.reasoning` |
| session | `gen_ai.conversation.id`, `session.id` | `session.id` |
| user | `user.id`, `enduser.id` | `user.id` |
| service tier | `openai.response.service_tier`, `openai.request.service_tier` | `llm.invocation_parameters.service_tier` |
| supplied cost | `cost.amount` | `llm.cost.total`, `cost.amount` |
| span kind | `gen_ai.operation.name` | `openinference.span.kind` |

Langfuse observations use `usageDetails` (`input`, `output`, `input_cached_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`, `output_reasoning_tokens`), `costDetails.total`, `model`, `modelParameters.service_tier` and trace-level `sessionId` / `userId`; see `tracecost.readers.langfuse`.
